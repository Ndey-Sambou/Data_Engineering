This is an End-to-End Data Engineering project. The project is designed to automate the extraction, transformation, and loading (ETL) of external financial data from multiple public source. It focuses on aggregating key financial indicators such as exchange rates, interest rates, inflation rates, and GDP data from APIs and open datasets like the World Bank, IMF, and Kaggle. The collected data is cleaned, standardized, and stored in structured formats (CSV files and a relational database) to support advanced analytics and AI model development. This pipeline simulates a real-world financial data workflow and demonstrates how raw, unstructured online data can be engineered into reliable, analysis-ready datasets for business intelligence, forecasting, and decision-making in the finance sector.
